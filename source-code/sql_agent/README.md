# Chapter 11 — Natural-language SQLite

A LangGraph ReAct agent equipped with `SQLDatabaseToolkit` that answers English-language questions about a small self-contained company database.

## Setup

```console
$ uv sync
$ ollama pull qwen3.5:4b
```

The first run will build `company.db` in this directory (a tiny SQLite file with four tables and ~20 rows). Delete it any time to reset.

### Model settings that matter

`_agent.py` configures `ChatOllama` with two options that are not optional for this example — leaving either at its default will break the agent:

- **`reasoning=False`** — `qwen3.5` is a "thinking" model. With thinking enabled it wraps its output in `<think>…</think>` tags that langchain-ollama strips from the visible content. That causes three failures: ollama raises an `XML syntax error` parsing the malformed tool-call stream, the agent loops on `sql_db_schema({})` because it forgets the required `table_names` argument, and the final answer comes back empty because the whole response lived inside the stripped think block. `reasoning=False` flips ollama's native `think` flag off so the model emits clean tool calls and a real final answer.
- **`num_ctx=16336`** — a ReAct run is long. The schema tool returns full `CREATE TABLE` statements plus sample rows, the query checker echoes the query back, and every tool call appends two messages. The default 2k context window fills up within the first couple of steps, truncating the system prompt or earlier tool results so the model loses track of what it has already done. 16k leaves comfortable headroom for a 6-step run.

## Scripts

| Script | What it shows |
|---|---|
| `_make_db.py` | Standalone; creates `company.db`. The agent scripts call this automatically if the file is missing. |
| `_agent.py` | Builds the `SQLDatabase`, wires up the toolkit, wraps everything in `create_react_agent`. |
| `01_sql_agent.py` | Asks four English questions and prints the agent's answers. |
| `02_stream_sql_agent.py` | Streams a single question so you can watch the agent write and execute SQL step by step. |

Run either driver:

```console
$ uv run 01_sql_agent.py
$ uv run 02_stream_sql_agent.py
```
